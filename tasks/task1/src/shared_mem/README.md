## nomutex.c

Код демонстрирует гонку данных при одновременном доступе нескольких потоков к общим переменным var1 и var2 без синхронизации. Программа выводит ошибки, потому что потоки нарушают условие var1 == var2

cc -Wall -Wextra -O2 -pthread src/shared_mem/nomutex.c  -o bin/nomutex
./bin/nomutex

## mutex.c

После добавления мьютекса вокруг операций var1++ и var2++ доступ становится последовательным, гонка устраняется, и переменные всегда остаются равными

cc -Wall -Wextra -O2 -pthread src/shared_mem/mutex.c  -o bin/mutex
./bin/mutex

## semex.c

Код демонстрирует синхронизацию потоков с помощью POSIX семафора

1.Создаётся семафор со значением 0 — все потоки, которые его ждут, блокируются
2.Запускаются 5 потоков потребителей, каждый вызывает sem_wait() и ждёт
3.Один поток производитель каждую секунду вызывает sem_post(), увеличивая счётчик семафора на 1
4.Это разблокирует один из ждущих потребителей, который выводит сообщение и снова ждёт
5.Каждую секунду один случайный потребитель получает разрешение на выполнение

cc -Wall -Wextra -O2 -pthread src/shared_mem/semex.c    -o bin/semex
./bin/semex

## prodcons.c

Код решает задачу «производитель–потребитель» с помощью условной переменной и мьютекса.

Есть 1 ячейка памяти (product) и флаг состояния (state):
 state = 0 - пусто, можно производить
 state = 1 - полный, можно потреблять

Производитель- ждет пока ячейка не освободится, кладет новое значение, сигнализирует потребителю.

Потребитель - ждет пока появится данные, забирает их, сигнализирует производителю.

cc -Wall -Wextra -O2 -pthread src/shared_mem/prodcons.c -o bin/prodcons
./bin/prodcons

## condvar.c

Код реализует машину состояний из 4 состояний с помощью 4 потоков и синхронизации через мьютекс и условную переменную

Состояние 0 - всегда переходит в 1 и увеличивает счётчик
Состояние 1 - переходит в 2, если счётчик чётный, или в 3, если нечётный
Состояния 2 и 3 - оба возвращаются в 0

Потоки ждут своей очереди, и только тот, чьё состояние наступило, выполняет переход

cc -Wall -Wextra -O2 -pthread src/shared_mem/condvar.c  -o bin/condvar
./bin/condvar
