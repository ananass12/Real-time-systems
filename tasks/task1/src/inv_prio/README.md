# Инверсия приоритетов

- Ситуация: высокий приоритет (H) ждёт мьютекс у низкого (L), а средний (M) вытесняет L, увеличивая задержку H.
- Эффект — временная «инверсия» порядка выполнения.

## scenario_2.c

Код демонстрирует решение проблемы инверсии приоритета с помощью мьютекса с наследованием приоритета (PTHREAD_PRIO_INHERIT)

## scenario_1.c

Код демонстрирует инверсию приоритетов на SCHED_FIFO без наследования.

## working.c

Код демонстрирует проблему инверсии приоритетов в многопоточных системах. Её можно решить с помощью наследования приоритета.

Без наследования приоритета высокоприоритетный поток вынужден ждать, пока низкоприоритетный освободит ресурс, но тот не может работать, потому что средний поток забирает процессорное время — возникает инверсия приоритета
