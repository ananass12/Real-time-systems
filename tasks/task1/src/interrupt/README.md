## int.c

Код демонстрирует, как в Unix системах можно эмулировать поведение аппаратных прерываний с помощью:
сигналов (SIGALRM),
интервального таймера (setitimer),
безопасного обработчика (async-signal-safe функции)

Программа печатает "100 events" каждую секунду и завершается через 10 секунд

## intsimple.c

Код демонстрирует обработку сигналов и ввода с клавиатуры

1. Настраивает обработку сигналов

SIGINT - Ctrl+C в терминале
SIGTERM - «вежливый» запрос на завершение 
SIGUSR1, SIGUSR2 - пользовательские сигналы 
SIGKILL - нельзя перехватить

Каждый сигнал устанавливает флаг (volatile sig_atomic_t), чтобы основной цикл знал, что произошло событие

2. Включает неблокирующий ввод с клавиатуры (raw режим терминала)

3. Работает в бесконечном цикле, пока не нажата 'q'
