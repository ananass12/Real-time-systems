## hello.c
Программа бесконечно выводит переданные ей аргументы командной строки, нумеруя каждую строку и делая паузу в 1 секунду между выводами

## intro.c
Программа запускает 3 параллельных потока (чтение символов с клавиатуры, ожидание изменений, отображение текущего состояния). Потоки синхронизируются с помощью мьютекса и условной переменной, чтобы избежать конфликтов с доступом. Работает бесконечно

## Сборка
cc -Wall -Wextra -O2 -pthread src/intro/hello.c -o bin/hello
cc -Wall -Wextra -O2 -pthread src/intro/intro.c -o bin/intro

## Запуск
./bin/hello Привет мир
./bin/intro
