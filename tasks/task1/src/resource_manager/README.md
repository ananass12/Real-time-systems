## resmgr.c

Запускает сервер на сокете /tmp/example_resmgr.sock
Принимает подключения и создаёт отдельный поток для каждого клиента
Обрабатывает сигналы SIGINT и SIGTERM для корректного завершения (удаление файла сокета)

Устройство хранит одно целое число (device_value) как своё состояние

Поддерживает три текстовые команды:
GET — вернуть текущее значение.
SET <N> — установить новое значение N.
INC — увеличить значение на 1.

Только первый подключившийся клиент получает права на запись (SET, INC). Все последующие клиенты могут только читать (GET)

Общий ресурс (device_value) защищён мьютексом (pthread_mutex_t), что гарантирует корректную работу в многопоточной среде
Обработчики сигналов используют _exit() для безопасного завершения без вызова деструкторов


## client.c

Простая утилита командной строки для взаимодействия с менеджером ресурсов.

Использование:
./client "GET"
./client "SET 42"
./client "INC"

Автоматически добавляет символ новой строки (\n) к команде — необходимо для корректного распознавания команды сервером

Отправляет команду и выводит полученный ответ. Поддерживает те же команды, что и сервер: GET, SET N, INC

Проверяет ошибки при создании сокета, подключении, отправке и приёме данных. Корректно завершает соединение после получения ответа.
